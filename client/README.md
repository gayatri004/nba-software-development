# NBA Software Development – Frontend

## Project Overview
The frontend of NBA Software Development provides a user-friendly interface for managing NBA accreditation data, institutional information, and administrative activities.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- React Router
- React Icons

## Features
- Admin Login
- Dashboard
- Employee Management
- Department Management
- Faculty Management
- Salary Management
- Attendance and Leave Management
- Course Management
- NBA Criteria Forms
- Master Forms
- Reports and PDF-related features

## Installation and Setup

### 1. Open the Client Folder
```bash
cd client
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Frontend
```bash
npm start
```

The application runs at `http://localhost:3000` by default.

## Backend Connection
The frontend communicates with the backend API to process data and interact with the PostgreSQL database.

## Project Purpose
To provide a centralized and user-friendly interface for NBA accreditation and institutional data management.
