# NBA Software Development – Frontend

## Project Overview

The frontend of NBA Software Development provides a user-friendly interface for managing NBA accreditation data, institutional information, criteria-related forms, and administrative activities.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- React Router DOM
- Axios
- React Icons
- Chart.js
- React Chart.js 2
- React Circular Progressbar
- Mammoth
- PDF.js
- XLSX

## Features

- Admin Login
- Dashboard
- Employee Management
- Department Management
- Faculty Management
- Salary Management
- Attendance and Leave Management
- Course Management
- NBA Criteria Forms
- Master Forms
- Reports and PDF-related features

## Installation and Setup

### 1. Open the Client Folder

```bash
cd client
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Frontend

```bash
npm start
```

The application runs at `http://localhost:3000` by default.

### 4. Create a Production Build

```bash
npm run build
```

## Backend Connection

The frontend communicates with the backend API to process requests and exchange data with the PostgreSQL database through the backend server.

## Project Purpose

To provide a centralized and user-friendly interface for NBA accreditation and institutional data management.
